2. CHECK INDIVIDUAL PORTS:
   Command: netstat -ano | findstr ":5173"
   Command: netstat -ano | findstr ":8002"
   Command: netstat -ano | findstr ":2567"
   
3. GET PROCESS NAME FROM PID:
   Command: tasklist /FI "PID eq <PID>" /V /NH
   Example: tasklist /FI "PID eq 12345" /V /NH
   Output:  node.exe    12345  Console    0    45,432 K
   
4. GET FULL COMMAND LINE:
   Command: wmic process where processid=<PID> get commandline,executablepath /value
   Example: wmic process where processid=12345 get commandline,executablepath /value
   Output:  CommandLine=C:\Program Files\nodejs\node.exe C:\...\src\index.js
            ExecutablePath=C:\Program Files\nodejs\node.exe

Parameters explained:
  -a  = All connections and listening ports
  -n  = Numeric (IP and port numbers instead of names)
  -o  = Display owning process ID
  /FI = Filter (condition to match)
  /V  = Verbose (detailed information)
  /NH = No header (suppress column headers)
