GLO Karts

About the Game

GLO Karts is a multiplayer 3D kart racing game featuring characters, tracks, and arenas from SuperTuxKart. Race across 18 unique courses or battle it out in 9 dedicated arenas — solo or with friends.

Controls

  • W / ↑ — Accelerate
  • S / ↓ — Brake / Reverse
  • A / ← — Steer Left
  • D / → — Steer Right
  • Space — Use Item / Drift
  • R — Reset Kart (if stuck)

Multiplayer

Create private or open lobbies, share the lobby code with friends, or use Quick Match for public queues. The host controls mode/settings and starts the match countdown.
